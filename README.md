# 七池 Mod 地图管理器

[中文](README.md) | [English](README_EN.md)

## 介绍

七池 Mod 地图管理器用于管理、加载和整理《Overcooked! 2》自制 Mod 关卡，支持地图浏览、封面提取、压缩包安装、启用/禁用和备份。

## 软件架构

.NET 9 WPF 桌面应用，核心由界面层、地图扫描与安装逻辑、Python UnityPy 提取脚本组成。

## 安装教程

1. 安装 .NET 9 Desktop Runtime。
2. 下载并运行 `OC2 地图编辑器.exe`。
3. 首次启动后选择 `Overcooked! 2` 目录或 `Overcooked! 2\BepInEx\plugins`。

## 使用说明

1. 左侧选择 MOD，中间查看地图。
2. 点击“安装 MOD”选择压缩包，或把压缩包拖进窗口。
3. 点击“启用 / 禁用 / 删除”管理关卡集，删除前会自动备份。
