# QiChi Mod Map Manager

[中文](README.md) | [English](README_EN.md)

## Introduction

QiChi Mod Map Manager is used to manage, load, and organize custom Mod levels for Overcooked! 2. It supports map browsing, thumbnail extraction, archive installation, enable/disable, and backups.

## Architecture

A .NET 9 WPF desktop application. Its core consists of the UI layer, map scanning and installation logic, and Python UnityPy extraction scripts.

## Installation

1. Install the .NET 9 Desktop Runtime.
2. Download and run `OC2 地图编辑器.exe`.
3. On first launch, select the `Overcooked! 2` folder or `Overcooked! 2\BepInEx\plugins`.

## Usage

1. Select a Mod in the left panel and view its maps in the middle panel.
2. Click "Install Mod" to choose an archive, or drag an archive into the window.
3. Use "Enable / Disable / Delete" to manage level sets. Files are backed up before deletion.
